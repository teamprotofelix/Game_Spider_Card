# MARIE · SPIDER ARCADE v1.2 Suit Souls

웹브라우저에서 직접 실행되는 **스파이더 솔리테어 + 판타지 보스 전투** 게임입니다.

## 실행 방법

1. ZIP 압축을 **해제**합니다. (`index.html`, `styles.css`, `app.js`, `spider-core.js`, `assets/` 폴더를 같은 폴더에 둡니다.)
2. `index.html`을 Chrome 또는 Edge 브라우저에서 더블클릭합니다.
3. 인터넷 연결 없이 플레이할 수 있습니다. 별도 설치, 서버, npm, CDN, 외부 폰트, API 키가 필요하지 않습니다.

## 스파이더 기본 규칙

- 총 104장, 10열, 카드 더미 5회(각 10장)로 진행합니다. 시작할 때 54장(왼쪽 4열 각 6장, 나머지 6열 각 5장)을 배치합니다.
- **1무늬/2무늬/4무늬** 난이도를 지원합니다.
- 한 단계 높은 숫자(가령 9 위에 8)를 놓을 수 있습니다. **무늬가 다른 카드 위에도** 놓을 수 있습니다.
- 여러 장을 동시에 옮기려면 **같은 무늬 + 내림차순**으로 연결되어 있어야 합니다.
- 비어 있는 열에는 이동 가능한 모든 카드/묶음을 놓을 수 있습니다.
- 동일 무늬의 **K-Q-J-10-9-8-7-6-5-4-3-2-A**가 아래로 연속되면 자동으로 제거됩니다. 8묶음을 완성하면 승리합니다.
- 남은 더미를 10열에 각 1장씩 배분하려면 **빈 열이 없어야** 합니다.
- 실행 취소, 추천 힌트, 전체화면, 일시정지, 키보드 단축키 및 PC/모바일 포인터 이동을 지원합니다.

## 아케이드 요소

- 4명의 보스가 2세트 완성마다 순서대로 등장합니다. 실제 승패는 스파이더 규칙으로 결정되며, 전투 연출은 **원래 카드 규칙을 훼손하지 않습니다**.
- 빠른 연속 이동(9초 이내)은 콤보 점수를 추가합니다.
- 카드 이동/공개/세트 완성으로 마력을 충전하고, 100 마력에 도달하면 **아케인 스트라이크**로 보스 보호막을 타격하고 보너스 점수 30점을 획득합니다. 카드 배열에는 영향을 주지 않습니다.
- 보스 보호막은 전투 진행 연출입니다. 스테이지 클리어는 오직 2개 세트 완성으로 판정됩니다.
- 자동 저장/복구와 난이도별 최고 점수 저장을 지원합니다. 저장 기능은 브라우저의 로컬 저장소 정책에 따라 비활성화될 수 있습니다.

## 조작

| 입력 | 기능 |
|---|---|
| 카드 드래그 | 카드 묶음 옮기기 (마우스/터치) |
| 카드 탭 → 목적 열 탭 | 묶음 옮기기 |
| U | 실행 취소 |
| H | 힌트 |
| D | 카드 더미에서 10장 배분 |
| SPACE | 마력 100일 때 아케인 스트라이크 (화면 포커스가 일반 영역일 때) |
| P | 일시정지/계속 |
| ESC | 선택 해제 |

## 파일 구조

- `index.html`: 화면, UI 및 버튼 구조
- `styles.css`: 카드 인터페이스·데스크톱·모바일 반응형 스타일
- `spider-core.js`: 독립적인 규칙/카드 이동/배분/완성/힌트 로직
- `app.js`: 게임 렌더링, 드래그/터치, 사운드, 스테이지, 로컬 저장
- `assets/`: **모두 로컬 WebP 그래픽** (배경/보스/스킬/카드 앞·뒷면)
- `tests/`: Node.js를 사용할 수 있을 경우 실행 가능한 규칙 테스트 (실제 게임에는 Node.js 불필요)

## 기술 및 보안

- `file://`에서도 실행되는 정적 HTML + CSS + JavaScript; 요청·웹소켓·원격 서체·외부 CDN 의존 없음.
- 이미지 원본은 그래픽 생성 도구를 통해 제작했고 WebP 형식으로 압축했습니다. 카드는 고해상도 320×448px 개별 그림 52종입니다.
- 게임 점수와 진행 상태는 해당 브라우저의 로컬 저장소에만 기록됩니다. 외부로 전송하지 않습니다.
- `build_assets.py`는 제작용 참고 스크립트로 최종 배포용 ZIP에는 포함하지 않았습니다.
